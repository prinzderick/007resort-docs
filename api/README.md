# API contracts

The contract of record is the **OpenAPI document generated by `otueke-api`**, published as a build artifact on each release (see [repository map](../architecture/02-repository-map.md#contract-flow)). This folder holds conventions and the human-readable endpoint map that stay useful alongside the generated spec:

- [`../architecture/15-api-conventions-and-endpoint-map.md`](../architecture/15-api-conventions-and-endpoint-map.md) — versioning, error format, pagination, idempotency, concurrency, and the initial endpoint list.

When `otueke-api` publishes its first `openapi/v1.json`, copy it here (or link to the release artifact) so client teams have one place to check the contract against these conventions.
