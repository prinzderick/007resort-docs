# Client system specification

`007_Resort_and_Spa_Integrated_Facility_Operations_System_Specification_v2.pdf` is the original client-supplied specification (v1.0, September 2026) that this platform is built from.

**Note on naming:** the project was originally referred to by the working name "Otueke" during early architecture work. It has since been renamed to **007 Resort & Spa**. The specification document's internal title page and body text still read "Otueke" — it is the client's original source document and is kept as received rather than edited. All architecture documents, ADRs, workflows and repositories elsewhere in this project use the current name. Where an architecture doc cites this spec (e.g. `[spec §6]`), treat "Otueke" in the cited PDF as referring to the same property now named 007 Resort & Spa.
